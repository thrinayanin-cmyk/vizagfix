-> About the Project

The GVMC Civic Reporting Platform is a web-based municipal grievance redressal system designed to improve transparency and accountability in the Greater Visakhapatnam Municipal Corporation (GVMC).

It enables citizens to report civic issues such as potholes, water leakage, garbage accumulation, and streetlight failures using geo-tagged photographs. Citizens can track complaint progress, while municipal field workers must upload after-repair photographs as proof of completion.

-> Problem Statement

-> Key Features
Google Authentication: Secure and easy login.
User Profile: Manage contact information, ward details, and preferences.
Citizen Dashboard: View ward alerts and complaint statistics.
File a Complaint: Upload photographs, detect GPS location, and select issue categories.
Complaint Tracking: Monitor real-time complaint status.
Complaint History: Maintain records of previous complaints.
Photo Verification: Field workers must upload after-repair photographs.
Before & After Comparison: Citizens can visually verify completed work.
-> Complaint Workflow
Citizen logs in using Google Authentication.
Uploads an issue photograph.
GPS automatically detects the location.
Selects a complaint category.
Complaint is assigned to the respective GVMC ward.
Field workers complete the repair or cleanup.
Field workers upload an after-work photograph.
Complaint is marked Resolved only after verification.
-> Complaint Status
Status	Description
Submitted	Complaint registered
Assigned	Forwarded to GVMC ward
Action Pending	Work awaiting completion
Resolved	Completion verified with photo evidence
